# TaskPlanner Workflow

- Read `.tasks/config.json` before changing the board.
- Select work from Next, then Backlog, unless the user chose a task.
- Move the selected task to In Progress before implementation.
- Add a concise `### Plan` when `aiPlanRequired` is enabled.
- Implement and verify the task, replace the plan with a short done summary, then move the complete task section to Done.
- Preserve task IDs, unrelated task sections, and all content outside TaskPlanner marker blocks.
